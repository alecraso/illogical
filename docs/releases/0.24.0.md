# illogical 0.24.0

**The daemon updates itself, and the app releases on its own.** From
this release the daemon and the desktop app ship apart. The daemon
offers *Update now* (or `illogicald update`) when a release is out, and
the app never replaces it. Joining a machine takes one approval, a
machine that control dropped says so, and agents get set up in one
click.

Download the app: [macOS (Apple silicon)](https://github.com/arugula-salad/illogical/releases/download/app-latest/illogical-desktop-macos-arm64.zip)
· [macOS (Intel)](https://github.com/arugula-salad/illogical/releases/download/app-latest/illogical-desktop-macos-x86_64.zip)
· [Linux AppImage](https://github.com/arugula-salad/illogical/releases/download/app-latest/illogical-desktop-linux-x86_64.AppImage)
· [Linux .deb](https://github.com/arugula-salad/illogical/releases/download/app-latest/illogical-desktop-linux-x86_64.deb)
· [Windows](https://github.com/arugula-salad/illogical/releases/download/app-latest/illogical-desktop-windows-x86_64-setup.exe).
Servers and machines without a screen: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`,
or on Windows `irm https://illogical.widgets.wtf/install.ps1 | iex`.
On a Mac at its screen, install.sh installs the app too (#318).

## New

- **The daemon updates itself** (#391). *Update now* in the page, or
  `illogicald update`. The app checks the daemon's protocol at launch
  (#390) and no longer replaces it (#392).
- **Joining a machine leads** (#326). Getting started's cloud step asks
  for the machine's code; that's the one approval it needs. Approving the
  app's own window is a separate, optional step, and one prompt can
  approve both.
- **Dropped by control, said** (#325). A banner with *Join again*,
  Getting started, `illogical status` and a notification in the app.
- **A refused approval names the check** (#327), and a browser the
  account removed says so before offering *Approve*.
- **Agents in one click** (#335). `illogical setup claude`, or *Use
  Claude Code with illogical* in Getting started, installs the ACP
  adapter and adds illogical's MCP server.
- **An agent block logs in as whoever started it** (#379): it carries
  the caller's `CLAUDE_CONFIG_DIR`, and a failed login says which login
  and how to log in to it.
- **Fewer MCP tools** (#349): 20 instead of 39, the ones with several
  jobs taking a `kind`. The old names still answer.
- **One launch switch** (#385): a `labs` file in the state directory
  turns on what a stranger doesn't get.
- Team machines' other owners can be @mentioned and invited (#386).

## Fixed

- **Two editors on one pane don't fight over its size** (#333). Typing
  takes the size only once its owner has been idle for 3 s; focus
  doesn't take it.
- `last_lines` and other pane text drop zsh's end-of-line `%` (#348).
- Reconnects: a message arriving in pieces answers a heartbeat, a link
  that dies right after its hello backs off, and the daemon logs how long
  each channel lasted (#369).
- A long command or diff in a permission card scrolls, so *Allow* stays
  reachable (#421).
