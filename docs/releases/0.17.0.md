# illogical 0.17.0

## New

- **Sharing a session with someone outside your teams asks them first.**
  They see who's sharing and which machine, and *Accept* or *Decline*;
  until then the machine isn't listed for them and its notifications
  don't reach them.
- **It says when there's a newer release** (#176). At most twice a day the
  daemon asks GitHub which release is the latest (nothing else is sent),
  and the top bar shows the command that updates this install: install.sh,
  Homebrew, or the desktop app. `--no-update-check` turns it off.
- **The desktop app updates an older daemon** (#176). When the daemon
  running as the service is older than the one the app carries, the app
  puts its own in its place, keeping the daemon's flags and your panes.
- **Delete your account** on control's page (#173): *Sign-in and
  account…* lists where you're signed in (sign one out, or everywhere) and
  your passkeys (remove one, never the last way in), and *Delete account…*
  removes the account with its devices, machines, sessions, passkeys,
  GitHub link, push subscriptions and team requests, after you type your
  login. A team you founded goes with it. Expired sessions are pruned.
- **Hosted control, ready for more people** (#174): 1 GB, an idle relay
  connection costs a fifth of what it did, per-account relay limits
  (connections, and a daily traffic budget while billing is off), and a
  continuous off-site backup with Litestream (to Cloudflare R2), restored
  automatically onto an empty volume.
- **`illogical web`** opens this machine's page in your browser, signed
  in. Programs and browsers on this machine now show the daemon's local
  token (`local-token` in its state directory): the CLI and `illogical
  mcp` use the Unix socket as before, the desktop app signs its window in
  by itself, and a browser needs `illogical web` once.
- **The site presents illogical control** (#185): what the hosted service
  does and can't see, and that it's free during the beta, provided as is.
  Link previews have a proper image, the site has a `favicon.ico`, a
  sitemap and HSTS, and it fits a phone's width without hiding overflow.
- **A privacy notice and terms for illogical control** (#172), at
  [/privacy](https://illogical.widgets.wtf/privacy) and
  [/terms](https://illogical.widgets.wtf/terms), linked from the site and
  control's sign-in page, with a contact address.
- **Check your account when a machine joins.** Once a join is approved,
  `illogicald join` (and Getting started) shows the account's fingerprint,
  and the machine trusts the account only after you say it matches the
  one on the device you approved from (*Add a machine?* and *Devices and
  machines…* show it). `--account FINGERPRINT` answers ahead, for scripts.

## Fixed

- **The Linux desktop app runs on more distros.** It's built on Ubuntu
  22.04 now, so the AppImage and the .deb start on Ubuntu 22.04 and 24.04,
  Debian 12 and 13 and Fedora 42 (glibc 2.35 or newer), and the release
  fails if anything in them needs more (#170). The .deb declares that
  minimum and says who made it.
- **install.sh finds the latest release without GitHub's API,** whose
  limit of 60 calls an hour is shared by everyone behind one address (#179).
- **The macOS zip has no `._*` files** inside the app when unzipped from a
  terminal (#177).
- Tightened how the daemon accepts callers on this machine's loopback.
- The CLI's socket, when its path is too long for the state directory, is
  now in a private directory of its own.
- *Agent on this* marks the issue's own text in the agent's prompt as the
  author's, and starts the agent with nothing allowed ahead of time.
- The Fountain runner's unit keeps its agents off this machine's loopback
  (`--allow-loopback` to let them use it).
- **Menus offer only what this machine is set up for** (#180): VM tabs and
  panes and *Sandboxes…* need wisp, *Fountain agents…* a Fountain login,
  *Fountain runner…* the runner's unit, and *Open a studio app…* a linked
  studio. `GET /api/host` says which (`features`).
- **Dev servers and VS Code in blocks say how to turn them on** (#171):
  without `--block-listen`, *Open a port…* and *Open in editor* explain the
  setup and link to it instead of failing; the site and README call them
  opt-in.
- **No author's defaults** (#181): `illogical fountain runner` points at
  this repository's setup script, names its key `illogical-runner`, and
  looks for agent-specs in `~/agent-specs` (or `--specs`,
  `ILLOGICAL_AGENT_SPECS`); the VS Code extension names the right
  repository.
- **Docs teach control, not hub wiring** (#182): more machines join control
  (`docs/advanced.md`), and `docs/control.md` explains signing in the
  desktop app.
- Control sends `Strict-Transport-Security`.
- **Claude Code and Codex in a terminal pane no longer "need you" just for
  going quiet** (#145). The daemon reads the agent's screen instead: a
  long think stays *working*, a permission prompt is *needs you* with what
  it asks, and a turn ending while you're elsewhere is *done*. No hooks
  needed. Other agents going quiet are idle, not "needs you".
- Hardened how control routes daemon access, push notifications and
  certificates.
- Hardened how daemons sign requests to control and join it. Daemons
  from before 0.17 keep working with control; a machine control already
  knows joins again only from 0.17 on.
- Hardened the desktop app's sign-in through the browser. An app from
  before 0.17 needs updating to sign in.
- Hardened control's rate limits and its GitHub App checks.
- Control doesn't start billing without its webhook secret.
- The docs say exactly what control can and can't see, and what you trust
  it with ([control-e2e.md](../control-e2e.md#what-holds-against-control)).
- **The daemon starts on machines with no CA certificates.** On a bare
  server or container without the `ca-certificates` package, illogicald
  went down at start. The daemon and the CLI now fall back to Mozilla's
  roots, bundled in, and say so once; the system's roots still come first.
