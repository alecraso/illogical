# illogical 0.20.0

**Chat, and the Linux app's titlebar back.** Every thread on every machine
now has one place to read and answer it, like a team chat, and the Linux
desktop app's window buttons work again when it shows control's page.

## New

- **Chat: every thread in one place** (#290). *Chat* in the bar, the
  phone's sheet or the command palette (`/#chat`) shows every thread (the
  ones 0.19.0 added to panes and sessions) on every machine you can reach.
  Each machine's sessions are the channels, and each pane's thread sits
  under its session, newest first, with your unread count and @mentions.
  The bar's button counts what's unread everywhere.
  - Read and answer a thread right there; `@agent` and quotes work as in
    the drawer.
  - *Go to pane* (or *Go to session*) takes you to what a thread is about,
    switching machines if it's on another one. Clicking a quote does too.
  - Escape, or picking a tab, goes back to the panes. On a phone the list
    and a thread take the screen in turn.
  - A machine's threads show once it's on 0.19.0 or later.

## Fixed

- **The Linux desktop app's titlebar** (#290). Once a machine was signed
  in to control (since 0.15.0), the window shows control's page, and the
  app only let local pages move its window: dragging the bar and the
  minimize, maximize and close buttons did nothing. The app now lets
  control's page use those window commands (and only those), including
  after the machine joins a different control.

## Development
