# illogical 0.23.0

**Steadier connections, and a cleaner first look.** Pages and the
desktop app stop reconnecting in storms, and a closed page no longer
leaves the machine slower for everyone else. A stranger meets only what
they can use. Removing a machine asks first, team members can add their
own machines, and Shift+Enter starts a new line in Claude Code.

## New

- **Images in agent blocks** (#250, #351). Paste, drop or 📎 an image or
  file into an agent block's composer. An agent that takes images gets
  the image; any other gets its path.
- **Team members add their own machines** to a team (#332, #358), without
  an owner. The team's owners can take a member's machine out again.
- **MCP knows its pane** (#345, #365). A Claude Code session in a terminal
  pane, with `illogical mcp`, reads and posts its own pane's thread
  without naming it, and `run` can split beside it.
- **History kinds** (#346, #364). Answers to cards and an agent block's
  steps are no longer failed commands: `history --failed` shows only
  commands, and `--kind` picks one kind.
- **A first look without our own setup** (#342, #343, #366). Fountain,
  studio, workspaces, VM tabs and guest ssh are hidden from `--help`, the
  README and the MCP tool list. They still work for anyone who knows the
  command.

## Fixed

- **Reconnect storms** (#369, #383). A page or app whose link kept dying
  tried again every half second for as long as it did, to every machine;
  it now backs off. A page that was hidden, or an app window behind
  others, dropped and reopened every link about every 15 s; it now asks a
  quiet machine to answer before giving up on it. Each link that closes
  logs why to the console.
- **Closed pages slowed the machine** (#368). A page or app that went
  away through control or the end-to-end channel stayed a client of the
  machine, and every keystroke flushed to all of them. Input on a
  long-running machine got slower and slower.
- **Shift+Enter** in a pane starts a new line in Claude Code instead of
  sending (#334, #361).
- **Remove asks in a dialog** (#357). A double-click on Remove revoked a
  machine, a device, a team member or a passkey for good.
- **A removed machine can join again** (#330, #356) with a new key, and
  is told why its old one is refused.
- **A second join from one machine** keeps the approval already given to
  the first (#329, #362).
- **Resumed agents after a reboot** (#376, #382) stay known as running,
  so a second reboot resumes them too.
- **With no sessions** the top bar stays, so the machine and account menus
  can be reached (#331, #363).
- **Paste an image on a phone** (#381): a long-press in a text box opens
  the browser's menu, not the pane's.
- **Control has a ceiling on relay sockets** for all accounts together
  (#344, #354); past it, pages and daemons are told so and wait 30–60 s.

## Compatibility

- The reconnect and keystroke fixes need the page or app on 0.23.0 and
  the machine on 0.23.0 respectively; each helps on its own.
