# illogical 0.4.0

illogical as tools for any agent: Claude Code, Codex or an agent block
runs commands in durable panes you can watch and take over, starts and
supervises other agents, and searches what happened yesterday. Panes cost
about half the memory they did.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **An MCP server** (M16). The daemon serves MCP at `/mcp`, and
  `illogical mcp` is a stdio bridge to it:

  ```sh
  claude mcp add illogical -- illogical mcp
  ```

  - **Tools:** `run`, `send_input`, `read_output`, `capture_screen`,
    `wait`, `list`, `close`, `history`, `search`, `open_port`,
    `start_agent`, `agent_respond` and `read_file`.
  - **Long calls:** they send progress, and before the client's timeout
    they return "still running" with an offset to resume from, so a long
    build never fails a tool call.
  - **Attribution:** a pane an MCP client started says so ("started by
    mcp:claude-code"), and history records its commands as theirs.
  - **Tokens:** clients without tailnet identity use
    `illogical mcp token --name N [--scope read]`. They are revocable with
    `--revoke`.
  - **Agent blocks** get the server automatically, scoped to their own
    tab.
  - **Permissions:** the README suggests a Claude Code permission set that
    allows the read-only tools and asks for the rest.

## Changed

- **Memory** (M9 step 1, #3). An idle pane costs about 1.8 MB of daemon
  memory instead of 3.3 MB, so 500 idle panes take 887 MB instead of
  1.6 GB.
  - **Scrollback:** at most 16 MiB is kept in memory per pane, instead of
    64 MiB (about 18 MB a pane). The full history stays on disk.
  - **Closing panes** gives their memory back: 500 panes closed down to
    one leave 35 MB, not 212 MB.
  - **The build:** libghostty is built with a patch that drops Zig's
    per-thread signal stack. It is still built ReleaseSafe.
- **History's directory filter** follows links and matches only that
  directory or below. On macOS, `/var/...` now finds commands recorded
  under `/private/var/...`.

## Fixed

- A page or tmux client that attaches while a program is in the middle of
  an escape sequence no longer shows stray text, and a full-screen program
  can't be corrupted by the snapshot (#53).
- Closing a pane right after starting it no longer leaves its program
  running, even if the daemon stops at once. The pane's shim now owns the
  hangup and the kill (#35).
- Under systemd 254 and later, pane and agent commands keep their `$`:
  `systemd-run` no longer expands `$VAR` and `$$`. Panes no longer inherit
  the service's own environment (#57).
- `illogical tui` on a Mac sends Alt as Alt (`ESC b`), not Option's
  character.
- An agent message longer than the socket's buffer no longer hangs the
  agent (it hit macOS's 8 KiB first).
- Text an agent reads no longer gets blank lines from the macOS terminal's
  doubled carriage returns.

## Not yet
