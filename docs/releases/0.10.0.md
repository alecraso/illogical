# illogical 0.10.0

Swarm themes: the swarm can be drawn as a city (#116).

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **Theme** in the swarm's bar: *blocks* (the swarm you know, still the
  default) or *city*. The city draws the same panes in 3D, and every part
  of it means one thing:
  - a block is a cluster (the same *Cluster by*); its rows are machines,
    and each pane keeps its lot until you regroup;
  - a building's height is how long its command has run, and it keeps the
    last command's height when that's done;
  - a lit roof means it's still running, a red roof that its last command
    failed;
  - its windows scroll while it prints, stay lit a while after, and go
    dark when it's quiet;
  - colour is kind; shape says whether it finishes (box), runs until
    stopped (drum), is an agent (hexagon), an editor (pentagon), or a pull
    request or issue (slab);
  - a beam rises from whatever needs you, taller the longer it waits;
  - a marker over a building is a teammate with it open, with a cone
    while they type.

  The rail, hover peeks, click to open, *Show* and notification links work
  as they do in blocks. *How to read the city*, under the legend, says all
  this on the page. Your choice is remembered per browser, and the city's
  3D library loads only when you pick it.
