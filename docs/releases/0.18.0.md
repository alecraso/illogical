# illogical 0.18.0

**Intel Macs and Windows.** illogical now runs on Intel Macs (macOS 13 or
later): the desktop app, the daemon and the CLI. Thanks to
@beauregardhenry, who built and used it on an Intel MacBook Pro (#228).
And there's a first desktop app for Windows: it reaches the machines in
your illogical cloud account, though panes don't run on Windows itself
yet.

Download: [macOS (Apple silicon)](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-macos-arm64.zip)
· [macOS (Intel)](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-macos-x86_64.zip)
· [Linux AppImage](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-linux-x86_64.AppImage)
· [Linux .deb](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-linux-x86_64.deb)
· [Windows](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-windows-x86_64-setup.exe).
Servers and machines without a screen: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **The Intel Mac app**, `illogical-desktop-macos-x86_64.zip` (#227). Like
  the Apple silicon one, it isn't notarized yet: the first time, open it,
  then choose *Open Anyway* in System Settings › Privacy & Security.
- **`install.sh` and Homebrew on Intel Macs.** `install.sh` picks the
  Intel build there, and a shell running under Rosetta on Apple silicon
  still gets the Apple silicon one. `brew install arugula-salad/tap/illogical`
  works on both.
- **The Windows app** (x86_64, #217), a per-user installer. It's a client
  for illogical cloud: sign in and it shows every machine in your account.
  There's no local daemon on Windows yet, so there's no *This machine*;
  that comes later in the Windows track (#224). It isn't signed yet: when
  SmartScreen stops it, choose *More info*, then *Run anyway*.
- **The phone's ☰ sheet** (#230) puts the everyday actions first, shows
  machines as chips grouped by whose they are, folds the other sessions to
  a line each, and sets *Close pane* and *Close tab* apart.
- **The site's download button** picks the Windows installer on Windows,
  and the Intel app on Intel Macs in Chrome, Edge and other Chromium
  browsers. Safari and Firefox don't say which chip a Mac has, so they
  offer Apple silicon with Intel beside it.

## For contributors

- `just build-macos-x86_64` and `just desktop x86_64` cross-compile the
  Intel build on an Apple silicon Mac. `just check-macos x86_64` lints it
  from Linux on every push.
- `just test-scripts` tests `install.sh` against a fake release, and
  fails when a release target or download is named in some places but
  not others.
- `.github/workflows/macos-intel.yml` tests and builds natively on
  GitHub's Intel runner, weekly and by hand. `windows.yml` lints the
  Windows app and builds its installer on pull requests too.
