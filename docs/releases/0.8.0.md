# illogical 0.8.0

Pull requests and issues from Forgejo, GitHub and GitLab as blocks. What
they wait on reaches the swarm's rail and the phone, and an issue can
start an agent's work.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **Pull request blocks** (M36, #88; GitHub M38, #90; GitLab M39, #91).
  - **Opening one:** `illogical pr [URL | OWNER/REPO#N | N]`, *Open pull
    request…* in a pane's menu, the + menu or the phone's sheet, a PR
    link clicked in a terminal (Shift-click still opens the browser), or
    the MCP tool `open_pr`.
  - **What it shows:** the PR's state, reviews, checks and timeline,
    re-read only when something changed (GitHub's unchanged polls cost no
    rate limit). `capture --text`, `history` and `search` see it too.
  - **Attention:** a review asked of you is a gate you can *Approve* from
    the rail or the phone. Red checks on your PR are *Failed*, with
    *Rerun* on GitHub and GitLab. Changes requested or a mention ask for
    you, and merged or green is *Done*.
  - **The code:** *Changes* opens a diff block on the PR's merge base and
    head, and *Checkout* a terminal in a worktree of its head, forks
    included.
  - **Logins:** illogical uses `tea`, `gh` and `glab` as you've logged
    them in and keeps no tokens. A public GitLab project reads without a
    login, read-only.
- **Agents draft, people send.** An agent's comment, review, merge or
  new issue (through MCP, or the CLI under Claude Code) waits as a card
  on the block. The owner or an editor edits, sends or drops it, and the
  block's history records who sent it. Your own calls go straight out.
- **Issue blocks and *Agent on this*** (M37, #89). `illogical issue
  [URL | OWNER/REPO#N | N]`, *Open issue…*, issue links, or MCP
  `open_issue`. *Agent on this* gives the issue a tab: a branch
  `iNN-<slug>` in its own worktree, an agent working on the issue, and
  the agent's PR joining the tab when it opens. `illogical issue new`
  opens one (an agent's is a draft).
- **Live updates** (M40, #92).
  - **GitHub:** illogical control receives the GitHub App's webhooks and
    tells your daemons which of their PR and issue blocks to read again.
    Blocks then poll every 3 minutes instead of every 5 seconds. Sign in
    to control with GitHub for this.
  - **Forgejo and GitLab:** *Live updates* on a block adds a webhook to
    the repository that posts straight to your daemon over the tailnet.
  - **Hosted boxes** with no `gh` login read GitHub through the App,
    read-only.

## Changed

- **Studio app blocks** show a card instead of a white frame when the box
  doesn't answer, with *Try again*. They can prompt the box's agent
  through hud, and the follower paces its work-board reads.
- MCP has nine more tools: `open_pr`, `read_pr`, `pr_comment`,
  `pr_review`, `pr_merge`, `open_issue`, `read_issue`, `issue_comment`
  and `issue_new`. The swarm has two more kinds, `pr` and `issue`.
