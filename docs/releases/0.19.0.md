# illogical 0.19.0

**Threads, and reaching further.** Every pane and every session now has a
thread where the people working on it talk, kept by the machine that runs
it, with @mentions on your phone and @agent for the pane's agent. And
illogical reaches further: the CLI goes through control to any machine on
your account, `--ssh` reaches (and sets up) any box you can ssh into, and
a guest with only OpenSSH can watch a pane. Thanks to @lex00, who built
nearly everything here except threads (#214).

## New

- **Threads on panes and sessions** (M61, #240). Every pane and every
  session has a thread where the people working on it talk: *Thread* in a
  pane's menu, *Session thread* in the session menu, or the bubble on a
  pane. It opens beside your panes, or full screen on a phone, and
  messages arrive live on every window. The machine that runs the pane
  keeps the conversation, so it survives restarts, stays after the pane
  closes, and turns up in `search`; control only ever relays it
  encrypted.
  - Watchers read; people who drive post. A private pane's thread is its
    owner's, and someone you shared with "from now" sees messages from
    then on.
  - Unread counts are yours alone: on the pane's bubble, a dot on the
    session button, and a folded corner on the pane in the swarm.
  - `@name` notifies them, on their phone too, and the notification opens
    the thread.
  - *Quote selection in thread* posts terminal output as a quote that stays
    readable after it scrolls away; click it to jump back to the output.
  - `@agent` (or `@claude`) in a pane's thread reaches that pane's agent as
    a follow-up, from whoever may drive it. Agents read and answer with
    two new MCP tools, `read_thread` and `post_thread`; add them to your
    permissions (README).
  - Threads need the machine on 0.19.0; on an older machine the menus
    don't offer them.
- **The CLI reaches your machines through control** (#149). `illogical
  login` makes the CLI one of your devices: it shows a link with a code,
  you approve it on a signed-in device (*Add a terminal?*), and check the
  account's fingerprint as a machine does (`--account FINGERPRINT`
  answers ahead). Then `illogical --host NAME run|ls|capture …` reaches
  any machine on your account, directly when one of its URLs answers,
  else through the relay, with nothing in `hosts.json` and no local
  daemon needed. `illogical hosts` lists control's machines above the
  local list, and `ILLOGICAL_VERBOSE=1` says which way a command went.
  `attach` and `tui` don't go through control yet. `illogical logout`
  forgets the CLI's key.
- **All your machines…** A joined machine's own page now has a host menu
  even when it's alone, with *All your machines…* opening control's page
  (#149).
- **Reach a box over ssh** (#154). `illogical --ssh me@box tui`, or
  `--ssh` on any command, uses your own `ssh` (your `~/.ssh/config`, keys
  and agent; a password or 2FA prompt shows in your terminal). The first
  time, if the box has no illogical, it offers to copy this version there
  over ssh (the box needs no network) and start its daemon so it outlives
  the login. Declining is remembered; `ILLOGICAL_SSH_INSTALL=yes` answers
  yes. While you're connected, panes on the box use your forwarded agent,
  so `git push` works from them (`ILLOGICAL_SSH_AGENT=no` keeps it here).
  A box on a different major version is refused, with an offer to
  upgrade it. `illogical hosts add box ssh://me@box` saves it for
  `--host box`. The web and the phone list ssh hosts as reachable from a
  terminal only.
- **Add a machine over ssh** (#155). `illogical --ssh me@box join` sets
  the box up over ssh, then shows its join code in your terminal to
  approve from your phone or the web. Afterwards it's an ordinary machine
  on control's page and ssh is out of the picture. A box that can't reach
  control says so, and stays reachable with `--ssh`. `illogical join`
  without `--ssh` joins this machine.
- **A pane for a guest who has only OpenSSH** (#198). `illogical share
  --guest %3`, or *Invite over ssh…* in the pane menu, gives you one
  `ssh` command to send someone. The username is a one-time token and
  the daemon's host key is pinned in the command, so nothing is saved on
  their side (OpenSSH 8.5 or later; older clients get a known-hosts line
  to save). The guest can only watch that pane: no shell, no commands, no
  forwarding. Read-only unless `--rw`, which types under the one-driver
  rule with the guest's `--name` on their input. Invites are single use
  unless `--reusable`, expire (an hour by default; a day at most, two
  hours with `--rw`) and end with the pane. `illogical guests` lists
  them and `guests revoke ID` cuts the guest off at once. The daemon's
  own ssh server (`--guest-ssh`, port 7684; `off` turns it off) listens
  only while an invite exists. For now the guest needs an address that
  reaches the machine; boxes behind NAT come later.
- **A command palette** (#139). Ctrl+Shift+P (Cmd+Shift+P on a Mac)
  finds any pane, tab or session menu action, and jumps to sessions,
  tabs, panes and workspace blocks by name, the swarm, or the next pane
  that needs you. Recent picks come first. In Firefox, which keeps
  Ctrl+Shift+P, it's *Command palette…* in the session menu; on the
  phone it's the sheet's *Commands* button.
- **Prompt an agent and wait for its turn** (#147). `illogical send %4
  --wait 'fix the test'` types into Claude Code or Codex in a terminal
  pane (or an agent block) and waits: exit 0 when it's done, 2 when it
  asks for you, 3 when nothing started within 5 seconds. The MCP tool
  `prompt_agent` does the same in one call. An agent already waiting on
  someone isn't typed at, and neither is a pane with no agent. If you
  copied the README's permissions block, add `mcp__illogical__prompt_agent`
  to `ask`.
- **A pane's agent conversation comes back after a restart** (#146).
  When Claude Code or Codex runs in a terminal pane, the pane remembers
  its conversation, and after a daemon restart or a reboot it runs
  `claude --resume` (or `codex resume`) in the agent's own directory. A
  restart policy you picked yourself is kept. If the transcript or the
  directory is gone, you get a shell with a one-line note. The restart
  menus show *Resume Claude Code conversation*.
- **Agents found through wrappers** (#145). A terminal's agent is
  recognized when it runs through runners, interpreters, `python -m`, Nix
  wrappers or Homebrew's Python, and no longer by any matching word.
  Claude Code's trust dialog, drawn while the pane was starting, is now
  read. `illogical describe %N --detection` shows what each screen rule
  saw and which fired.
- **Standing permission rules for agent blocks** (#166). *From now on…*
  on a permission card keeps a rule on this machine: the tool, or
  commands starting with a prefix, in the block's directory and below or
  in every agent block. New blocks never ask for what a rule allows.
  *Permission rules…* in the session menu, or `illogical rules`, lists
  them and forgets them (`--forget N`, `--forget-all`).
- **The desktop app's titlebar is its tab bar** (#130). On macOS new
  windows (Cmd-N, the tray's *New window*) join as native tabs, and a
  tab's menu has *Open in new window*. Cmd-W closes the pane and Cmd-T
  opens a tab. On Linux the bar has its own minimize, maximize and close.
- **A global hotkey** for the desktop app, off by default: the tray's
  *Global hotkey*, or `hotkey_on` and `hotkey` in `desktop.json` (default
  Ctrl+Alt+Space). It hides a focused window and brings it back. On Linux
  the app stays in the tray when its last window closes while the hotkey
  is on.
- **`illogical://` links:** `illogical://pane/%N` opens a pane and
  `illogical://open?cwd=DIR` opens a directory, on macOS and Linux (an
  AppImage registers itself).
- **The Mac app starts its own daemon at login.** On a Mac with no
  daemon, the app in `/Applications` registers its bundled daemon, so it
  shows under Login Items, and an update restarts it on the new binary.
  A Mac where `illogicald install` already set one up keeps it.
- **The desktop app follows a join** (#204). Join or leave control while
  the app is open and its windows move with it: to sign-in or control's
  page after a join, back to the machine's page after a leave.
- **More downloads:** a `.dmg` beside the zip for each Mac, an `.rpm`,
  and the Linux app (`.deb`, `.rpm`, AppImage) for arm64 too, named
  `illogical-desktop-linux-aarch64.*`.
- **A Mac you only reach over ssh.** `illogicald install` on a Mac whose
  user hasn't logged in to the desktop installs a background agent that
  outlives the ssh session, and says it won't start again after a reboot
  until you log in or run it again (`illogical --ssh` does that for you).
  `illogicald install --system` starts the daemon at boot with nobody
  logged in: run it as yourself, and it prints each `sudo` step before
  running it.
- **`illogicald uninstall`** removes whichever service is installed (the
  agent, the LaunchDaemon, or the systemd user service on Linux).
  Binaries and state stay.
- **Cancel a one-click invite** (#134). A team lists the links nobody has
  used yet, each with *Cancel*, and control refuses a cancelled one.
- **Getting started joins your own control** (#207). Start the daemon
  with `--control https://control.example.com` (or `ILLOGICAL_CONTROL`)
  and the *Connect* button joins that control and says its name.
- **More passkeys work** (#205). Control accepts RSA passkeys, which some
  Windows Hello setups and security keys use.
- **Passkeys have names** (#208). The account panel shows "Windows Hello"
  or "Passkey from Chrome on macOS", with when it was added and last
  used. Older passkeys keep their number.
- **Team members show the names they set** (#208), not a one-word
  version ("Sam Stranger", not "Sam-Stranger").
- **Deleting an account tells its team** (#206). When a founder deletes
  their account, the team's machines are cut off at once, not at their
  next check, and members get a notice in the app as well as the push.

## Fixed

- **A remote host that drops off the network** now shows as unreachable
  in its panes within about 7 seconds, and they're live again about a
  second after it's back, with what it printed meanwhile (#17). They
  used to stay "live".
- **Panes keep their command across restarts.** `illogical ls` lost a
  pane's command after a daemon restart (#208), and a pane set to rerun
  its command gave a plain shell from the second restart on.
- **Invite links** (#208): an accepted link leaves the address bar, so a
  reload no longer offers it again or says it expired, and *You're in*
  stays up when joining switches machines.
- **A machine whose account was deleted** says so when it tries to join
  again, and points at `illogicald leave` (#208).
- **A machine downgraded after its team used a one-click invite** logs
  that illogical needs an update, instead of keeping an old member list
  (#135).
- The share dialog no longer mentions throwaway VMs on a machine that
  can't make them (#208).
- On an iPhone, tapping a swarm tile no longer opens the pane and then
  switches straight back. In the swarm's city, taps no longer miss
  buildings that have moved.
- A terminal agent's state kept updating while a client asked about it
  many times a second; before, it could stay stuck for 20 seconds.
- `illogical --host` no longer sends your local directory to the other
  daemon with `run`.

## For contributors

- **[docs/testing.md](https://github.com/arugula-salad/illogical/blob/main/docs/testing.md)**
  covers every test, fake and fixture, and what each guards. No test
  waits for a person: the manual and real-device checks became tests
  (#214).
- **Docker is required.** Tests that need Docker or tart fail without
  them, saying what to run; only `ILLOGICAL_SKIP_DOCKER=1` and
  `ILLOGICAL_SKIP_MACOS_VM=1` skip, loudly. Tests that need a secret or
  an account skip and name it.
- **The test stack** (`testnet/`, `just testnet up|test|break`): `ssh`,
  `control` and `tailnet` profiles in Docker, each claim with a `BREAK=1`
  form that must fail. Stacks are named by `COMPOSE_PROJECT_NAME`, so
  worktrees don't share boxes. `just forges`, `just testnet-hosts` and
  `just testnet-editors` run real Forgejo and GitLab, two hosts, and VS
  Code over Remote-SSH; `forges-nightly.yml` also runs against github.com
  when its accounts are set (#93).
- **`crates/testkit`** starts daemons and services for the Rust tests; 14
  harnesses moved onto it.
- **A headless approving device**, `web/fixtures/device.ts`, approves
  join codes and sign-ins the way the browser does, for shell, Rust and
  Playwright tests.
- **A replay agent** (`crates/vt/fixtures/agents/`) plays recorded Claude
  Code and Codex sessions as `claude` or `codex`.
  `ILLOGICAL_REAL_AGENTS=screen` runs the same tests against the real
  ones.
- **A throwaway macOS VM** with tart: `just macos launchd`, `safari`,
  `iterm2` and `app` check launchd with no GUI session, real Safari,
  iTerm2 and the desktop app on Apple silicon.
- **Phone tests** in Playwright device contexts (Pixel 7, iPhone) with a
  fake push service.
- **CI runs Playwright** (Chromium and WebKit on Linux, WebKit on macOS)
  and the test stack's `ssh` and control profiles. `just browsers`
  installs Playwright's browsers.
- **Desktop app:** `just desktop-linux ARCH` builds the Linux packages
  (the release builds arm64 under qemu-user), `just desktop-xvfb` runs the
  Linux app under Xvfb and `just desktop-packages ARCH` installs the .deb
  and .rpm. Developer ID signing and notarization (`scripts/macos-sign`,
  #177) and updater signatures run in the release when their secrets are
  set, and say they skipped otherwise. The Tauri updater is registered
  only in builds with a public key in `tauri.conf.json`, and updates the
  macOS app and the AppImage only.
- **The workspace compiles on Windows** (#218). check.yml has a
  `windows-x86_64` job: clippy and the unit tests for every crate except
  `control`. Nothing changes on Linux or macOS.
