# illogical 0.16.0

**Agents you can start already trusted.** An agent block can start with
tools it may use without asking, a permission mode, or your own Claude
Code settings, so a lead agent can hand out work that doesn't stop at a
card for every `Read` (#163). And on a Mac, agent blocks now find the
Node your shell has (#161).

· [Linux AppImage](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-linux-x86_64.AppImage)

## New

- **Start an agent with rules, a mode, or your settings** (#163, #167).
  - `illogical agent --allow TOOL` (repeatable), or `allow` on MCP
    `start_agent`: the block approves that tool's requests without a
    card, as "always" on its card does.
  - `--permission-mode MODE`, or `permission_mode`: the session starts in
    `acceptEdits`, `plan`, `auto` or the agent's own mode, and goes back
    to it each time the block reopens. If the agent refuses the mode, the
    transcript says so.
  - `--user-settings`, or `user_settings` (Claude Code only): your allow
    and deny lists, default mode and `CLAUDE.md`, with every hook off, as
    an opened conversation has.
  - `start_agent` won't start an agent in `bypassPermissions` (or Codex's
    `full-access`): only you start one with every check off.

## Fixed

- **Agent blocks run with your shell's environment** (#161, #162). Under
  launchd the daemon's PATH is the bare system one, so with Node from nvm
  or Homebrew every Claude Code agent failed with "Claude Code's adapter
  needs Node 20+". Agents and the adapters' status and Install now use
  your shell's PATH, as panes do. Agents restored just after the daemon
  starts wait for it.
- **An idle agent wants you once a turn, not on every redraw** (#168).
  Without the Claude Code hooks, an agent that had finished and redrew
  itself (a resize, its status line) went "needs input" again, with a new
  notification, each time. Now it's once per turn, armed by your input or
  a new command.
- **Even padding around the terminal** (#164, #165). Panes were sized
  from a cell measured with the wrong renderer, which left a gap at the
  right of the text in the app and the browser. The text now fills the
  pane, with 8px to the window's edges.

## Known issues

- Codex's `full-access` mode id is untested.
- `--user-settings` brings in your own default mode, which could be
  `bypassPermissions`.
- None of the new agent options are in the web *Start an agent…* dialog
  yet.
