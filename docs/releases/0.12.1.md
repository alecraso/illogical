# illogical 0.12.1

illogical now lives on GitHub: [arugula-salad/illogical](https://github.com/arugula-salad/illogical).
Issue and PR numbers carried over unchanged, and every release from
v0.1.0 is there with its downloads. No changes to illogical itself.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## Changed

- **Releases come from GitHub.** `install.sh` and the Homebrew formula
  download from GitHub releases.
- **The Homebrew tap moved** to `arugula-salad/homebrew-tap`. If you
  tapped the old one:

  ```
  brew untap jhgaylor/tap
  brew tap arugula-salad/tap
  brew install illogical
  ```

  The old tap stays at 0.12.0.
- **The old Forgejo repo** (`git.inevitable.fyi/jhgaylor/illogical`) is
  archived. Its release downloads keep working.
