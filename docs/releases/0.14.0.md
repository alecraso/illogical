# illogical 0.14.0

**The desktop app.** illogical for macOS (Apple silicon) and Linux
(x86_64) as an app you download, in place of installing a daemon from a
terminal: download it from <https://illogical.widgets.wtf>, open it, and it
sets itself up. Also: Getting started in five steps, where the commands
it used to ask you to type are buttons.

Download: [macOS](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-macos-arm64.zip)
· [Linux AppImage](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-linux-x86_64.AppImage)
· [Linux .deb](https://github.com/arugula-salad/illogical/releases/latest/download/illogical-desktop-linux-x86_64.deb).
Servers and machines without a screen: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **The desktop app** (#130, #144). Your machine's illogical in a native
  window, the same client the daemon serves, so the two always match.
  - **It installs the daemon.** The app carries `illogicald` and
    `illogical`. The first time it opens on a machine without a daemon, it
    installs both in `~/.local/bin` and starts the daemon as a service
    (launchd on macOS, systemd on Linux), as `illogicald install` does.
    Your terminals keep running when the window closes.
  - **Every key reaches your terminals:** Cmd-W, T, N and Q on macOS, and
    F10 on Linux.
  - **Native notifications** when a pane starts needing you; a click opens
    it. The needs-you count is on the Dock badge (macOS) and the tray.
  - A tray icon with *New window*. Links to other sites open in your
    browser.
  - The macOS app isn't notarized yet. The first time, open it, then
    choose *Open Anyway* in System Settings › Privacy & Security.
- **Getting started, in five steps** (#143): Welcome, Phone, Cloud,
  Agents, Ready, with a step rail and a summary of what's left. It's in the
  session menu any time (closing it says so).
  - **Put it on my tailnet** runs `tailscale serve` for this machine and
    shows its address as a QR code. When only you can fix something (a
    one-time sudo, HTTPS certificates in Tailscale's admin console, turning
    on Serve) it says what, with the command or the link.
  - **Connect to illogical cloud** shows a join code and an *Approve*
    button, and turns into *Joined* by itself once you approve.
  - **Add illogical to Claude Code** runs `claude mcp add` for you.

## Fixed

- **On a Mac, the daemon now finds Tailscale.** Run from launchd, the
  Tailscale app's binary tried to open its window instead of answering as
  the CLI, so the daemon never learned the machine's tailnet address.

## Known issues

- The Linux app is x86_64 only; arm64 machines use the terminal install.
- After joining the cloud, a machine's own page and the app list only the
  machines added to it, not the account's others. That's next.
