# illogical 0.6.1

A fix for VS Code blocks.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## Fixed

- **Blank editor blocks** (#69). A VS Code block could stay blank when the
  app and the blocks are on different sites (the app on `*.ts.net`, the
  blocks on their own domain) in a browser that blocks third-party cookies.
  The browser refused the block its storage, and VS Code stopped loading.
  - The block's site now puts a small script first in its pages. It stands
    in for `localStorage` and `sessionStorage` when the browser refuses
    them. VS Code's settings live on the server, so nothing is lost.
  - VS Code frames its own pages for its in-browser extension host, and
    blocks now allow that. They are still framed only inside the app.
  - The block site logs the requests it refuses, at debug level:
    `RUST_LOG=illogicald::sites=debug`.
