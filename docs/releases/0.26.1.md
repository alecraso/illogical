# Arugula 0.26.1

**Arugula's own addresses.** The project is at
[github.com/arugula-salad/arugula](https://github.com/arugula-salad/arugula)
and [arugula.io](https://arugula.io), and this release names them: links,
install commands and the update check. The old addresses still work:
GitHub forwards the old repository's links and downloads, and
illogical.widgets.wtf still serves the install scripts.

Update: *Update now* in the page, or `arugulad update`.

- The install commands are `curl -fsSL https://arugula.io/install.sh | sh`
  and, on Windows, `irm https://arugula.io/install.ps1 | iex`.
- Mail for security, privacy and anything else goes to `security@`,
  `privacy@` and `hello@arugula.io`.
- **Homebrew:** newer Homebrews load a tap's formulas only once it's
  trusted: `brew trust arugula-salad/tap`. After that, `brew upgrade`
  moves an `illogical` install to `arugula`.
