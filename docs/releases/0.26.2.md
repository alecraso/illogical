# Arugula 0.26.2

Fixes from the rename.

- **The update check follows a renamed repository** (#525). It reads
  `releases/latest` through any redirects to the release tag, so a move like
  this week's can't hide new releases again. Daemons on 0.26.0 or older
  didn't find 0.26.1 for that reason: update them once with
  `curl -fsSL https://arugula.io/install.sh | sh` (Windows:
  `irm https://arugula.io/install.ps1 | iex`). From 0.26.1, *Update now*
  finds this release.
- **install.sh works where /tmp is noexec** (#532): it unpacks the release
  under `~/.cache/arugula`.
- **Control** notes daemons and CLIs still signing in at its old address
  (#535), so it can tell when that address is no longer needed.
