# illogical 0.5.0

Editors join the swarm: VS Code in a block on any machine, your own
VS Code, Cursor or nvim followed from the phone, and Claude Code's edits
as cards you accept from anywhere. The terminal UI gets copy mode.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **VS Code blocks** (M27). VS Code (code-server) on a folder, on a pane's
  machine: this host, or a VM.
  - **Opening one:** *Open in editor* on a pane, *Edit* in the swarm, or
    `illogical edit PATH[:LINE]`.
  - **One server per machine.** It's downloaded on first use (pinned, with
    checksums), reached over a private socket, and stops when idle.
  - **Restarts:** after a daemon restart, or after code-server itself
    dies, the block reopens at its file and line.
  - **Who can open it:** the owner only.
- **Your editor in the swarm** (M28). VS Code and Cursor (with the
  illogical extension, `illogical editors install`) and nvim
  (`editors/nvim`) join the swarm once you ask, per folder.
  - **What the swarm shows:** each editor's project, file, errors and
    unsaved files.
  - **Following:** tap an editor to follow its cursor in a read-only view,
    from the phone too. From there you can Continue a paused debugger, open
    the file in your editor, or ask Claude about the lines.
  - **New cards on the rail:** a debugger paused, errors after a save, a
    merge conflict.
  - **Claude Code's edits as cards.** In a terminal pane, illogicald is
    Claude Code's IDE. Each edit it proposes is a diff card beside the
    terminal and on the rail: Accept, Change… or Reject, from any device.
    Claude Code outside illogical never picks it, and `--no-claude-ide`
    turns it off.
- **Copy mode in `illogical tui`** (M32).
  - **Selecting:** drag selects (Shift-drag when the program takes the
    mouse), a double-click selects a word and a triple-click a line.
  - **Copying** goes through OSC 52, so it works over ssh.
  - **`Ctrl-] [`** enters copy mode, with vi keys and `/ ? n N` search
    through the pane's whole saved history, not just what's on screen.
  - **Prompt marks:** `[ ]` jump between prompts, and `o` selects a
    command's output.
- **MCP for agent blocks in a VM** (#59). An agent block in a VM gets
  illogical's MCP tools through a relay into the VM, still scoped to its
  tab. What it runs lands on its own machine.

## Changed

- **History's folder filter** and every "file relative to its project"
  follow links, so macOS `/var` and `/private/var` match.
- **`--listen 127.0.0.1:0`** lets the daemon choose its port and write it
  to `state/listen`.

## Fixed

- A command's captured output could come back empty when the program
  exited quickly: the exit was applied before its last output (#60).
- An agent that started and exited between two checks was reported as
  failing to start (#64).
- A new VM agent could exit at once: the daemon wrote to it before the
  VM's boot script had finished its environment (#65).

## Not yet

- Real hardware for most of the above: VS Code over Remote-SSH from a
  laptop, following from a real phone, OSC 52 in iTerm2 and on a phone's
  terminal, and a real Claude Code edit accepted from the rail.
- The VS Code extension and the dev container feature aren't published
  to a marketplace yet. Install the extension with
  `illogical editors install`.
