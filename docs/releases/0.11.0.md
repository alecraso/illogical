# illogical 0.11.0

Two more swarm themes, the hive and the timeline (#117); every host's
Claude Code conversations in one picker (#78); and "typing" in the swarm
now means typing (#118).

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **Hive** and **timeline** under *Theme* in the swarm's bar, beside
  blocks and city.
  - The hive is a hex cell per pane in a comb per cluster: the fill is how
    long its command has run (full at an hour), the edge pulses while it
    prints, a red rim is a failed last command, and a pane that needs you
    takes the reason's colour and glows onto its neighbours, wider the
    longer it waits.
  - The timeline is a lane per pane over the last 40 minutes, now at the
    right edge: bars are commands, coloured by kind, striped by how fast
    they print, red-capped when they fail; a band runs from when a pane
    started needing you until now.

  *How to read* under the legend explains each, as it does for the city.
- **Conversations from every host** in the web picker, each under its
  machine's name, as they answer. One on another host opens there.
  `illogical claude ls --host all` does the same in a terminal (#78).
- An opened conversation **marks what Continue won't remember**: entries
  off the branch Claude Code resumes from are folded and dimmed (#79).

## Fixed

- **Typing, driving, watching** (#118). The swarm called a pane's driver
  "typing" for as long as they held it, which was until their last
  browser tab closed. Now:
  - "typing" lasts a few seconds after their last keystroke;
  - a driver shows on a pane only while they look at it or type in it,
    as "driving" when they're there but not typing;
  - a driver who hasn't typed in a pane for 10 minutes lets it go, so the
    next person to type drives it without taking control.
- Conversations on macOS: whether Claude Code is still running, and
  which pane holds it, work without /proc or systemd (#81).
- An opened conversation's block names only this daemon's panes, not
  another daemon's on the same machine (#77).
- Following a long transcript converts only what was appended: 0.2 ms
  instead of 39 ms a change on a 30 MiB one (#80).
- Safari keeps its device keys across reloads, so approvals it signs are
  trusted (#94). Control logs why it refused an enrolment or approval.
