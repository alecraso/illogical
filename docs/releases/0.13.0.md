# illogical 0.13.0

One-click team invites: an owner makes a link, the invitee presses Join,
and they're in, with no approval step afterwards (#126, by @lex00). Also:
terminal panes scroll with a swipe on phones (#132, by @alecraso).

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **Presigned team invites.** When an owner makes an invite link, their
  device signs it ahead of time: the team, the role, an expiry and a
  one-time key. The invitee's device uses that key to add them to the
  roster itself, so pressing Join is the whole of joining.
  - The one-time key's private half lives only in the link's
    `#pinvite=` fragment, and never reaches control. Through a GitHub
    sign-in it waits in the browser's session storage. Control still
    can't add anyone by itself.
  - Links work once, last at most 24 hours, and never grant owner.
    *Ask me first* keeps the old request-then-approve link, and owner
    invites always use it.
  - Daemons now report what they understand. Control makes a one-click
    link only when every daemon checking the team (its machines, and any
    a session was shared with) is 0.13.0 or later; otherwise the owner
    gets an *Ask me first* link and a note naming the machines to update.
    Upgrade your team's machines to turn one-click links on.
  - Owners get a notification when someone joins.

## Fixed

- **Swiping a terminal pane scrolls it on touch devices** (#132). xterm.js
  6 only scrolls on the wheel, so swipes were dropped. Now a vertical
  swipe scrolls the scrollback with a fling, or sends wheel reports to a
  program that tracks the mouse (arrows on the alt screen). A tap still
  focuses the terminal and brings up the keyboard.

## Known issues

- Cancelling a single outstanding invite link isn't possible yet (#134).
- A machine downgraded to an older illogical after a one-click join stops
  at the team's newer roster (#135).
- One-click joining hasn't been tried in Safari (#137). Touch scrolling
  hasn't been tried on iOS.
