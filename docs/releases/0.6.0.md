# illogical 0.6.0

See what an agent changed from your phone, and rerun what failed. A tab
can now hold panes from other machines.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **Changes: diff and file blocks** (M11).
  - **Opening it:** *Changes* on a pane, a tab, the phone's sheet or a
    swarm tile.
  - **The diff block** lists what changed in the repository on that
    machine (the working tree, a revision, or a range), with +/− counts
    per file. Each file opens to its hunks.
  - **The file block:** tapping a line opens the file live at that line,
    and the mark follows edits.
  - **Updates:** both update only while someone is looking, so a VM can
    sleep.
  - **Viewers** of a shared session see both and can't change them.
  - **Also:** `illogical diff`, `illogical view PATH[:LINE]`, the MCP
    tools `show_changes` and `show_file`, and *Open file* on an agent's
    tool calls.
- **Rerun.** A failed command's *Failed* reason offers Rerun. It's on the
  phone, in the swarm, on the push notification, on the tab's badge, in
  `illogical tui` and as `illogical rerun %N`. It types the command again
  only when the shell is idle at its prompt.
- **Panes from other machines in your tabs** (#17).
  - **Making one:** *New tab on HOST* and *Split right on HOST*, or
    `illogical --host HOST run --home [--split %N]`, put a shell on
    another host in this daemon's layout.
  - **The terminal** connects straight to that host, which keeps its
    size, history and restart policy.
  - **While the host is down,** the pane greys out and comes back on its
    own.

## Changed

- `illogical open` and `illogical agent` take `--machine mN` (as `edit`
  does). `--host` is always another daemon. The documented
  `open --host m2` never worked, and now says what to use (#61).
- `--block-listen` and illogical-control's `--listen` accept port 0, and
  write the port they got to `state/block-listen` and beside control's
  database.
- Menus scroll when they're taller than the window.
- `run --session NAME` for a new session starts the session with that pane
  alone.

## For contributors

- Browser tests reserve only `E2E_PORT`: every other daemon, control and
  fake server gets its port from the OS (`web/e2e/ports.ts`), so two
  worktrees can run the suite at once (#67). They no longer leave
  directories in `/tmp` (#62).

## Decided

- **Parking panes (M9 step 2, #10) is not needed now.** Idle panes are
  1.8 MB since 0.4.0, and geek runs 7 panes in 25 MB. PLAN.md says when to
  revisit it.
- **S8:** job and service blocks (M10) aren't worth their own block types.
  Terminals do jobs, and Rerun covers acting on a failure. Diff and file
  blocks were built instead.

## Not yet

- Real hardware: Changes and Rerun on a real phone, and a mixed-host tab
  across real separate machines.
