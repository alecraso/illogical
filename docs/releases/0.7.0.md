# illogical 0.7.0

Work in a chant workspace and a studio app from illogical. A gate waiting
in either one is something the phone can approve.

Install or upgrade: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`

## New

- **chant workspace blocks** (M34, #73).
  - **What it shows:** `illogical workspace [DIR]` opens a workspace as a
    block, with its members as cards and its records with their state.
    You can also use *Open as workspace* in a pane's menu or the picker,
    or the MCP tool `open_workspace`.
  - **Working in a member:** *Shell*, *Agent* and *Changes* open a
    terminal, a Claude agent or a diff in that member, and *Run op* runs
    `chant run <op>` in a pane. A nested workspace opens as another block.
  - **Gates:** a gate waiting in any member is attention. It shows on the
    swarm's rail, on the phone's sheet (gates first) and in
    `illogical tui`. *Approve* runs chant's own `approve` as the person
    who tapped it (`--approver`), and chant's ledger names them.
    The owner and editors may approve; viewers can't (#75).
  - **Freshness:** the block reads through the workspace's own chant
    (`$CHANT`, `node_modules/.bin`, or PATH), never fetches, and re-reads
    only when git says something changed.
- **Studio app blocks** (M35, #85).
  - **Opening one:** an arugula-salad studio app opens as a block from
    *Open a studio app…*, `illogical app [NAME]` or the MCP tool
    `open_app`.
  - **Questions:** the box's agent's questions are asks on the block, on
    the swarm's rail and on the phone. Answering them in illogical
    carries the agent's turn on.
  - **Gates:** a release waiting at chant's `ship` gate is attention you
    can approve.
  - **Getting in:** run `illogical studio login <studio>` with a personal
    token from the studio's settings. Entry links are minted each time
    and never kept, so the block comes back after a restart.
  - **Naming who answered:** with a follower link (`hud share --role
    follower` in the box, then `illogical studio follower APP`), hud and
    chant name whoever answered or approved.
- **Asks on browser blocks.** `illogical ask` and `POST
  /api/panes/{id}/ask` take browser and app blocks, not only terminals.

## Changed

- **Blocks that run your tools** (workspace blocks, and later others)
  get your shell's environment, so node from mise, nvm or fnm in
  `.bashrc` is found (#74). It is read once per host from your login
  shell, with a 10 s limit. `illogical shell-env [--refresh]` shows or
  re-reads it. Panes are unchanged.
- The project page shows the other kinds of block.
