# Arugula 0.26.0

**illogical is now Arugula.** The commands are `arugula` and `arugulad`,
and control is at [control.arugula.io](https://control.arugula.io).
Updating keeps everything you have: open panes, your machines' places in
control, your keys and settings. Update from illogical 0.25 (*Update
now* in the page, or `illogicald update`); from an older one, run the
install script again.

Download the app: [macOS (Apple silicon)](https://github.com/arugula-salad/illogical/releases/download/app-latest/arugula-desktop-macos-arm64.zip)
· [macOS (Intel)](https://github.com/arugula-salad/illogical/releases/download/app-latest/arugula-desktop-macos-x86_64.zip)
· [Linux AppImage](https://github.com/arugula-salad/illogical/releases/download/app-latest/arugula-desktop-linux-x86_64.AppImage)
· [Linux .deb](https://github.com/arugula-salad/illogical/releases/download/app-latest/arugula-desktop-linux-x86_64.deb)
· [Windows](https://github.com/arugula-salad/illogical/releases/download/app-latest/arugula-desktop-windows-x86_64-setup.exe).
Servers and machines without a screen: `curl -fsSL https://illogical.widgets.wtf/install.sh | sh`,
or on Windows `irm https://illogical.widgets.wtf/install.ps1 | iex`.

## What changes when you update

- **The daemon's service** becomes `arugulad` (systemd unit, launch agent
  or scheduled task), taking over from `illogicald` in place: panes keep
  running.
- **`illogical` and `illogicald` still work**: they're links to `arugula`
  and `arugulad` now (copies on Windows), so scripts and Claude Code hooks
  keep working until you update them.
- **Your state stays where it is.** A machine that had
  `~/.local/state/illogical` keeps it, with `~/.local/state/arugula` as a
  link to it; the same for `~/.config/illogical`. `ILLOGICAL_*` variables
  still work beside the new `ARUGULA_*` ones.
- **Control moves to control.arugula.io.** Joined machines follow it by
  themselves, without joining again. In browsers and on phones, sign in
  at control.arugula.io, approve that browser from one still signed in at
  the old address, and add a passkey there: passkeys and approved browsers
  belong to the address they were made at. The old address keeps working
  meanwhile.
- **Claude Code:** run `arugula hooks install` to rename the hooks, and
  `arugula setup claude` (or *Use Claude Code with Arugula* in Getting
  started) to register the MCP server as `arugula`; it replaces the
  `illogical` one. Its tools are now `mcp__arugula__*`: rename any
  `mcp__illogical__*` rules in Claude Code's own settings. Rules Arugula
  keeps itself, on cards and agent blocks, still match.
- **Homebrew:** `brew upgrade` moves `illogical` to `arugula`.
- **Editors:** Neovim configs that use `illogical` keep working
  (`require("illogical")`, `vim.g.illogical`, `:IllogicalJoin`). The VS
  Code extension is now `arugula.arugula-editor`, and it replaces the old
  one where the daemon installs it.

## Also

- Control answers at more than one address while it moves, and each
  browser is served as the address it came in on (#507).
- Downloads are published under their old names too (`illogical-*`), so
  older daemons and links keep finding them.
